Agent Bazaar project brief. Agent Bazaar is a multi-agent system that validates third-party services before a developer relies on them. The system maps service listings to a shared ontology and stores them in a knowledge graph. The Client agent finds, ranks, composes and executes tools, while the Auditor verifies provider claims with documentation and live probes. The Mapper learns from corrections and repairs drifted mappings. The project uses free resources and reports its results against two baselines: plain LLM tool-calling and retrieval without the ontology. The main goal is to make third-party service use discoverable, verifiable, composable and self-healing. The demonstration chains geocoding, weather and currency tools, shows claim badges, and recovers from an injected provider outage using a compatible substitute.
